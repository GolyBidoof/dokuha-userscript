One script for all five stores: BookWalker, ebookjapan, CMOA, Kindle and k-manga. It reads the viewer's own signed CDN URLs, fetches every page file directly, rebuilds each page offline at full resolution, and hands you the pages as one ZIP you can rename to .cbz, without turning a single page.

This is the v3.0.0 rewrite of the earlier Omnimanga Native Downloader listing (BookWalker, CMOA and ebookjapan, version 2.0.0): same GreasyFork entry, now with the Kindle and k-manga stores added.

  • Original-resolution pages, one file per page. The Mokuro hand-off files them as Series/Volume/page-0001.jpg. Full editions, free and trial samples, and subscription viewers.
  • "Also available on" pills under the book details cover the five shops the availability index knows: whether each one carries the series, what this volume costs and how much of the run is free, linking to the product page rather than a viewer. Amazon names the size of the run and claims a Kindle Unlimited count only once it has seen every volume of it, since one set of results never lists the whole series. A shop that does not carry the book gets no pill at all.
  • Reading stats before you commit: Natively level with JLPT band colours, ratings and reader counts, plus Manga Kotoba vocabulary totals.
  • Optional Mokuro OCR through the separate, locally running mokuro-bridge service. Pages stream across as they are descrambled and come back as the .cbz / .mokuro / .webp trio that reader.mokuro.app reads, delivered to a local folder, MEGA, Google Drive, OneDrive, WebDAV or whichever other destination the bridge is configured for. A mokuro-bunko library gets the same volume files, but there the bridge leaves series.json to bunko, which compiles the library metadata itself.
  • Resume, not restart: pages are cached as they arrive, an interrupted run continues where it stopped, and a partial failure names the pages that are missing.

Only need one store? The repository also carries smaller single-store builds that contain no other store's code: BookWalker Native Downloader, CMOA Native Downloader, ebookjapan Native Downloader, Kindle Native Downloader and k-manga Native Downloader. Install one of those or the combined script, never both.

Needs a userscript manager (Tampermonkey or Violentmonkey). The stats cards and store pills read each shop's public page, so Tampermonkey asks for cross-origin access to them; decline it and downloading and OCR work exactly the same.
